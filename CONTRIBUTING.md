# Contributing to CorpusForge

Thanks for helping build practical, transparent NLP tooling. Search existing issues before opening a new one, and include reproducible examples with **synthetic** text only.

1. Fork the project, then create a branch (`feat/your-change` or `fix/your-change`).
2. Install locally: `python -m pip install -e ".[dev]"`.
3. Add a test that demonstrates the bug or feature.
4. Run `pytest -q` and `ruff check src tests`.
5. Open a pull request describing motivation, implementation, and limitations.

**Security and privacy:** never upload private datasets, credentials, or real PII in issues, PRs, or examples. If you discover a vulnerability, contact the maintainer privately at tejassarnaik2120@gmail.com instead of publishing an exploit.

Be respectful and constructive in issues and discussions. Maintainers may close abusive or off-topic submissions.
