# Security policy

This project is provided on a best-effort, community-maintained basis. For a potential security vulnerability, please email **tejassarnaik2120@gmail.com** with a minimal synthetic reproduction. Avoid public disclosure until the issue can be assessed.

CorpusForge processes text locally. The regex masking feature is deliberately **not** advertised as complete PII removal or compliance with any regulation. Do not assume redacted output is safe to disclose without additional validation.
